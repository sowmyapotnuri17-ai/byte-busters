AI Government Scheme Finder

Project Overview

The AI Government Scheme Finder helps users discover government schemes relevant to their needs using Retrieval-Augmented Generation (RAG).

Technologies Used

- Python
- Retrieval-Augmented Generation (RAG)
- Streamlit

Objective

To make it easier for people to find relevant government schemes and understand their eligibility criteria using information from official government sources.

Current Status

Project notebook uploaded to GitHub.

Future Enhancements
